# WebApp Desafio Desenvolvimento

Projeto de desafio da empresa [NetSpeed](https://www.netspeed.com.br/), um simples sistema de gerenciamento de chamados.

## Tecnologias utilizadas

- [Frontend] ASP.NET Core MVC, Razor Pages, Bootstrap 3.4.1 e jQuery;
- [Backend] C#.NET Core 2.1 e .NET Framework 4.7.2;
- [Database] SqlLite;

OBS: o template do projeto foi disponibilizado (primeiro commit), com tecnologias antigas, e o desafio em si não tratava de atualizá-las, mas
de focar nas entregas das tarefas solicitadas no escopo.

## Como executar localmente

### Pré-requisitos

- [.NET Core SDK 2.1 ou superior](https://dotnet.microsoft.com/download)
- [.NET Framework 4.7.2 ou superior](https://dotnet.microsoft.com/download/dotnet-framework/net472)]
- [Git](https://git-scm.com/downloads)
- [Visual Studio 2019 ou superior](https://visualstudio.microsoft.com/pt-br/downloads/) (opcional, mas recomendado)

### Passos para executar a aplicação.

1. Clone o repositório via git;
2. Navegue até a pasta do projeto e execute o comando `dotnet run`;
3. Ou, abra-o no Visual Studio (não o code) e execute F5.
